# єСвітло в Google Play

## Картка магазину

Назва — єСвітло. Мова — українська. Тип — безплатний застосунок.

Короткий опис — Графіки відключень, віджети та сповіщення для обраних черг.

Повний опис

> ЄСвітло показує графіки відключень електроенергії на сьогодні й завтра для доступних регіонів України. Оберіть регіон і чергу, щоб бачити інтервали відключень за київським часом.
>
> Додайте кілька локацій для дому, роботи чи близьких і перемикайтеся між ними. Відкрийте список усіх черг регіону або додайте віджет на головний екран.
>
> Окремо налаштуйте сповіщення про зміни графіків, новий графік на завтра та попередження оператора. Кожен тип можна вимкнути або отримувати без звуку.
>
> ЄСвітло — незалежний застосунок. Фактичні відключення можуть відрізнятися від графіка. Перевіряйте стан за конкретною адресою у свого оператора мережі.

Політика конфіденційності — https://yesvitlo.pp.ua/privacy.html

## Відомості для Data safety

- Firebase Cloud Messaging і Firebase Installations обробляють ідентифікатор інсталяції, реєстраційний токен та технічні відомості для роботи push. Підписки передають коди регіону й черги до FCM. Дозвіл Android на показ сповіщень окремий від автоматичної ініціалізації SDK.
- API отримує код регіону та обробляє IP для обмеження частоти запитів. Перед заповненням декларації перевірте політику зберігання журналів на проксі й CDN.
- Назви локацій і параметри зберігаються локально. Обліковий запис, GPS і рекламні SDK відсутні.
- Звірте категорії й призначення даних із [довідкою Firebase](https://firebase.google.com/docs/android/play-data-disclosure) та фактичними налаштуваннями сервера. Переносьте в Play Console лише перевірені відомості.

## Внутрішній тест

Перед першим завантаженням налаштуйте Play App Signing із чинним ключем підпису APK, якщо потрібне оновлення встановлених GitHub-версій. Після реєстрації ключа завантаження підпишіть ним AAB. Додайте тестувальників у Play Console та перевірте встановлення через посилання участі в тесті.
