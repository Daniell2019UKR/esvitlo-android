# єСвітло для Android

Нативний застосунок на Kotlin і Jetpack Compose з Material 3 Expressive. Потрібен Android 8.0 (API 26) або новіший.

Застосунок показує добові графіки на сьогодні й завтра за київським часом. Регіон і черга зберігаються на телефоні. Завантажений графік залишається доступним без мережі до завершення відповідної доби. Стани «Світло є», «Відключення» і «Немає даних» відображаються окремо. Червона картка показує повідомлення оператора, якщо воно доступне.

Графіки надходять із публічного [API єСвітло](https://github.com/Daniell2019UKR/esvitlo/blob/main/docs/api.md) через HTTPS. Поки застосунок відкритий, він перевіряє графік кожні 30 секунд. Кнопка «Оновити» запускає перевірку одразу. Обидва способи читають серверний кеш.

## Тема

За замовчуванням застосунок повторює світлу або темну тему Android. У меню «Тема» можна вибрати власний режим. На Android 12+ палітра береться із системи. На Android 13+ іконка підтримує системне тонування, коли ввімкнено тематичні іконки й launcher підтримує їх.

## Збірка

Відкрийте каталог `android` в Android Studio з JDK 17 та Android SDK 36 або виконайте `./gradlew :app:assembleDebug` (`gradlew.bat :app:assembleDebug` у Windows). APK для локального встановлення з’явиться в `app/build/outputs/apk/debug/app-debug.apk`.

На Windows використовуйте шлях до проєкту без кирилиці. Під час першої збірки Gradle завантажить залежності з Google Maven і Maven Central.
